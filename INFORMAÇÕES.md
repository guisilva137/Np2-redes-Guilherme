Chat Cliente-Servidor com Sockets em Python

Este projeto demonstra a comunicação entre um cliente e um servidor utilizando Sockets TCP em Python.
A aplicação permite a troca de mensagens em tempo real diretamente pelo terminal,
simulando uma conversa simples entre duas máquinas conectadas em uma rede.

Funcionalidades:

Conexão cliente-servidor utilizando TCP/IP.
Envio e recebimento de mensagens em tempo real.
Comunicação bidirecional pelo terminal.
Encerramento da conexão através de um comando definido pelo usuário.
Exemplo prático para estudo de Redes de Computadores e programação com sockets.

Tecnologias Utilizadas:

Python 3

Biblioteca socket

Como Funciona:

O servidor inicia e fica aguardando conexões em uma porta específica.
O cliente se conecta ao servidor utilizando o endereço IP e a porta configurados.
Após a conexão, cliente e servidor podem trocar mensagens através do terminal.
A comunicação permanece ativa até que um dos lados encerre a conexão.
